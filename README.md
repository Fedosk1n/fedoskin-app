# Fedoskin team — альфа-версия

Веб-приложение-база элементов брейкинга от Fedoskin team. Открытая альфа: все уроки бесплатно, разбор видео платный (через Telegram).

## Что внутри

- `index.html` — всё приложение (экраны, плеер, поиск, профиль, рейтинг).
- `admin.html` — админка: уроки, загрузка видео, тексты и цены, статистика. Адрес: https://fedosk1n.github.io/fedoskin-app/admin.html
- `lessons.js` — список уроков (его меняет админка).
- `config.js` — тексты и настройки (их меняет админка).
- `v/` — видео уроков:
  - `<id>.mp4` — сам урок (720p, 60 кадров/с);
  - `<id>.jpg` — обложка;
  - `<id>-p3.mp4` — анимация обложки (первые 3 секунды, без звука).
- `logo.png`, `icons/`, `manifest.json` — логотип и иконки для «На экран Домой».

## Как добавить новый урок

Сами: админка → «Добавить видео» → «Kinescope» → выбрать файл (исходник, любой длины), раздел, название → «Подготовить урок» → «Опубликовать».
Короткие ролики можно и по-старому, в GitHub (кнопка «GitHub», до 70 МБ после сжатия).

Перенести готовый урок в Kinescope: «Уроки» → урок → «Загрузить файл в Kinescope» (или вставить ссылку на видео из Kinescope) → «Готово» → «Опубликовать».
Токен и проект Kinescope вписываются один раз: «Тексты и настройки» → «Kinescope». Они хранятся только в браузере.

Или через Claude:
1. Пришлите видео в чат Claude с подписью «раздел — название».
2. Claude сожмёт видео, сделает обложку и анимацию, положит файлы в `v/` и добавит строку в `lessons.js`
   с датой `added` — урок 14 дней будет со значком NEW.
