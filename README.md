# Fedoskin team — альфа-версия

Веб-приложение-база элементов брейкинга от Fedoskin team. Открытая альфа: все уроки бесплатно, разбор видео платный (через Telegram).

## Что внутри

- `index.html` — всё приложение (экраны, плеер, поиск, профиль, рейтинг).
- `lessons.js` — список уроков. Добавить урок = добавить одну строку.
- `v/` — видео уроков:
  - `<id>.mp4` — сам урок (720p, 60 кадров/с);
  - `<id>.jpg` — обложка;
  - `<id>-p3.mp4` — анимация обложки (первые 3 секунды, без звука).
- `logo.png`, `icons/`, `manifest.json` — логотип и иконки для «На экран Домой».

## Как добавить новый урок

1. Пришлите видео в чат Claude с подписью «раздел — название».
2. Claude сожмёт видео, сделает обложку и анимацию, положит файлы в `v/` и добавит строку в `lessons.js`
   с датой `added` — урок 14 дней будет со значком NEW.
