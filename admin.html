Вход

Админка сохраняет изменения прямо в GitHub. Для этого нужен ключ доступа (токен). Его делают один раз на каждом устройстве — дальше админка его помнит.

Как получить ключ

  1. Откройте github.com/settings/personal-access-tokens/new (нужно быть в аккаунте Fedosk1n).
  2. Token name — любое, например Админка Fedoskin. Expiration — выберите самый долгий срок (через год ключ надо будет сделать заново).
  3. Repository access → Only select repositories → выберите fedoskin-app.
  4. Permissions → Repository permissions → Contents → Read and write. Больше ничего не трогайте.
  5. Внизу нажмите Generate token, скопируйте ключ (начинается с github_pat_) и вставьте сюда.

Ключ хранится только в этом браузере и никуда, кроме GitHub, не отправляется. Никому его не пересылайте. Если телефон потеряется — удалите ключ на той же странице GitHub.

Подключите Cloudflare R2 — один раз, минут 5. Бесплатно до 10 ГБ

  1. Откройте dash.cloudflare.com → слева R2 Object Storage (раздел Storage & Databases). Если Cloudflare попросит включить R2 и привязать карту — привяжите: при наших объёмах (до 10 ГБ) платить ничего не придётся.
  2. Нажмите Create bucket → имя fedoskin-video → Create bucket. Остальное не трогайте.
  3. Слева Workers & Pages → fedoskin-push → вкладка Settings → Bindings → Add → R2 bucket. Variable name: VIDEOS (большими буквами), R2 bucket: fedoskin-video → Deploy (или Save).
  4. Обновите код сервера: → там же, в fedoskin-push, кнопка Edit code → выделите всё, удалите, вставьте → Deploy.
  5. Вернитесь сюда и нажмите

Качество видео

    Если сжимаете на телефоне

    Проще всего: в CapCut экспортируйте видео в 720p, 30 или 60 кадров, выберите его здесь и нажмите «Без сжатия». Можно и 1080p — тогда ролик весит в 3–5 раз больше. Файл должен быть меньше 70 МБ — это ограничение GitHub. Обложку и анимацию админка сделает сама.

    Альфа-тест

    Онлайн услуги

    На русском показываются 4 услуги в рублях: разбор, онлайн-ведение, тренер для тренера, полное ведение. На всех остальных языках — 3 услуги в долларах: онлайн-ведение, полное ведение, консультация. Тексты услуг меняет Claude.

    В приложении кнопка «Написать тренеру» предлагает выбрать мессенджер. Пустое поле — этого мессенджера в списке нет.

    Оплата криптой

    Иностранцы видят на странице услуги кнопку «Оплатить криптой (USDT)»: сумма, QR-код и адрес твоего кошелька. В русской версии кнопки нет.

    Так увидят клиенты

    Проверь: отсканируй этот QR-код камерой или кошельком — адрес должен совпасть с твоим. Сверь первые и последние 4 символа:

    Как поменять кошелёк — пошагово
    1. Открой кошелёк (Trust Wallet, Tonkeeper, биржа…) → USDT → «Получить» / «Пополнить».
    2. Выбери сеть TRON (TRC-20). Не ERC-20, не BEP-20, не TON — у них другие адреса.
    3. Скопируй адрес (начинается с T, 34 символа) и вставь в поле выше — кнопкой «Вставить из буфера» или вручную.
    4. Дождись зелёной галочки и сверь первые и последние 4 символа с кошельком. Отсканируй QR в превью.
    5. Нажми «Опубликовать» внизу экрана. Через 1–2 минуты у клиентов будет новый адрес.
    6. Сделай тестовый перевод 1–2 USDT на новый адрес, чтобы убедиться, что деньги доходят.
    Безопасность
    • Нужен только адрес. Никогда никуда не вставляй секретную фразу (12 или 24 слова) и приватный ключ — с ними кошелёк могут украсть. Админка такие фразы не примет.
    • Переводы, отправленные клиентами раньше, остаются на старом адресе — не удаляй старый кошелёк, пока не выведешь деньги.
    • Если берёшь адрес на бирже, проверь, что биржа принимает USDT именно в сети TRON и не меняет адрес со временем.

    Подключите счётчик посещений — один раз, минут 5, бесплатно

    Счётчик работает на том же сервере Cloudflare, что уведомления и рейтинг. Нужно добавить к нему бесплатную базу данных и обновить код сервера.

    1. Откройте dash.cloudflare.com → слева Storage & Databases → D1 SQL Database → Create (или «Create database»). Имя: fedoskin-stats → Create.
    2. Нажмите кнопку ниже — код сервера скопируется. Затем слева Workers & Pages → fedoskin-push → Edit code: удалите всё в окне с кодом, вставьте скопированное → Deploy.
    3. Вернитесь к fedoskin-push → Settings → Bindings → Add → D1 database. Variable name: DB (большими буквами), база: fedoskin-stats → Deploy / Save.
    4. Нажмите «Проверить». Цифры начнут расти с первого захода в приложение.
