Вход

Админка сохраняет изменения прямо в GitHub. Для этого нужен ключ доступа (токен). Его делают один раз на каждом устройстве — дальше админка его помнит.

Как получить ключ

  1. Откройте github.com/settings/personal-access-tokens/new (нужно быть в аккаунте Fedosk1n).
  2. Token name — любое, например Админка Fedoskin. Expiration — выберите самый долгий срок (через год ключ надо будет сделать заново).
  3. Repository access → Only select repositories → выберите fedoskin-app.
  4. Permissions → Repository permissions → Contents → Read and write. Больше ничего не трогайте.
  5. Внизу нажмите Generate token, скопируйте ключ (начинается с github_pat_) и вставьте сюда.

Ключ хранится только в этом браузере и никуда, кроме GitHub, не отправляется. Никому его не пересылайте. Если телефон потеряется — удалите ключ на той же странице GitHub.

    Статистика

    Яндекс Метрика подключена

    Посетители, страны, города, телефоны — в отчётах Метрики. Какие уроки смотрят: Отчёты → «Параметры визитов» (цель lesson). Нажатия «Написать в Telegram»: цель review_tg. Сколько человек установили приложение на экран «Домой»: цель app_install (смотрите «Достижения цели»), сколько раз его открывали с иконки: цель app_open.

    Открыть Метрику
    Подключите Яндекс Метрику — это бесплатно

    Тогда вы будете видеть, сколько людей заходит, откуда они и какие уроки смотрят.

    1. Откройте metrika.yandex.ru/add и войдите в Яндекс.
    2. Имя счётчика — Fedoskin. Адрес сайта — fedosk1n.github.io/fedoskin-app. Галочку «Вебвизор» можно включить.
    3. Нажмите «Создать счётчик». Код вставлять никуда не надо — скопируйте только номер счётчика (8–9 цифр).
    4. Вставьте номер во вкладке «Тексты и настройки» → «Номер счётчика» и нажмите «Опубликовать».
    5. В Метрике → «Цели» добавьте четыре цели типа «JavaScript-событие» с идентификаторами: lesson (открыли урок), review_tg (нажали «Написать в Telegram»), app_install (установили на экран «Домой»), app_open (открыли приложение с иконки).

    Уведомления

    Сервер уведомлений ещё не подключён

    Один раз, минут 10, бесплатно. Пошаговая инструкция — в чате с Claude или в файле server/README.md в репозитории. В конце вставьте адрес сервера во вкладке «Тексты и настройки» и нажмите «Опубликовать».
