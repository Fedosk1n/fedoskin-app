# Закрытый пилот ИИ-ассистента Fedoskin Team

По умолчанию ассистент не запускается. Пилот работает только в чате одного нового тестового браузера. Клиентский интерфейс и перевод ответов тренера не меняются. Модель выбирает язык и тему, но не пишет сообщения самостоятельно: клиент видит только заранее подготовленные ответы. Языки пилота: русский, английский и испанский. Скидок нет; актуальная полная цена берётся пользователем из карточки услуги, а не из текста модели. Нет обещаний по сроку ответа, обработки оплаты и разбора вложений моделью.

## Изолированный тест

1. Не разворачивать этот PR на рабочем Worker. Создать отдельный тестовый Worker с отдельными KV PUSH, D1 DB и тестовым Telegram-ботом. Подключить Workers AI как AI; R2 VIDEOS нужен только для теста вложений. Скопировать код Worker из ветки пилота. Привязать только свой тестовый Telegram по штатной процедуре админки, настроенной на тестовый Worker.
2. Запустить локальную копию приложения с отдельным браузерным профилем и тестовым pushUrl в config.js. Открыть чат, чтобы приложение сгенерировало идентификатор. В консоли этого профиля посмотреть `localStorage.getItem('fedoskin-chat-id')`. Не копировать значение `fedoskin-chat-key`. Добавить только идентификатор свежего профиля как `CHAT_ASSISTANT_TEST_ID` в настройки **тестового** Worker. Не использовать ID реального клиента. Удаление настройки выключает ассистента.
3. Написать «¿Hay descuento?» из приложения. Клиент видит испанское приветствие, объяснение, что Fedoskin ответит лично, и ответ, что скидок нет. Тренер видит сообщение клиента и отдельную подписанную заметку с ответом ассистента.
4. Написать «¿Cómo funciona?». Ассистент отвечает про формат ведения без повторного приветствия. Ответить в Telegram по-русски: в приложении появляется ответ тренера с существующим переводом. После этого ассистент больше не отвечает в этом диалоге. Для повторного прогона использовать новый тестовый профиль и его идентификатор.
5. Проверить, что чат из другого профиля не получает ответ ассистента. До проверки не использовать реальные сообщения, вложения или токены.

Локальная проверка: `node tools/test_chat_assistant.mjs` (заглушки Telegram и Workers AI, настоящие SQL-запросы к SQLite).
