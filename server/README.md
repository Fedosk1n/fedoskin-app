# Сервер уведомлений о новых уроках

Маленькая программа на Cloudflare (бесплатно). Она хранит, кто подписался на уведомления,
и рассылает пуш «Новое в Powermove: Headspin», когда в админке публикуется новый урок.
Код — `push-worker.js` в этой папке. Своих паролей у сервера нет: отправлять уведомления может только
тот, у кого есть ключ GitHub с правом записи в репозиторий приложения (то есть ваша админка).

## Как поставить (один раз, ~10 минут)

1. Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (почта + пароль, карта не нужна).
2. Слева **Storage & Databases → KV → Create** (или «Create instance»). Имя: `fedoskin-push` → **Create**.
3. Слева **Compute → Workers & Pages → Create → Start with Hello World** (или «Create Worker»).
   Имя: `fedoskin-push` → **Deploy**.
4. Нажмите **Edit code**. Удалите всё в окне с кодом, вставьте целиком содержимое файла `push-worker.js` → **Deploy**.
5. Вернитесь к воркеру → вкладка **Settings → Bindings → Add → KV namespace**.
   Variable name: `PUSH` (большими буквами), KV namespace: `fedoskin-push` → **Deploy / Save**.
6. Скопируйте адрес воркера — вида `https://fedoskin-push.<ваше-имя>.workers.dev`.
   Откройте его в браузере: должно появиться `{"ok":true,"service":"fedoskin-push"}`.
7. Админка → **Тексты и настройки → Адрес сервера уведомлений** → вставьте адрес → **Опубликовать**.

Готово. Во вкладке «Статистика» видно число подписчиков и есть ручная отправка.
После публикации нового урока админка сама отправит уведомление через 3 минуты.

## Ограничения бесплатного Cloudflare
- до 100 000 запросов в день и до 1 000 новых подписок в день — для альфы с огромным запасом;
- рассылка идёт пачками по 40 телефонов, админка сама гоняет пачки до конца.

## Где работают уведомления
- iPhone (iOS 16.4+): только в приложении, добавленном на экран «Домой».
- Android: в Chrome и в установленном приложении.
- Компьютер: Chrome, Edge, Firefox, Safari.
