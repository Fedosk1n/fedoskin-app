# Сервер приложения: уведомления о новых уроках и рейтинг

Маленькая программа на Cloudflare (бесплатно). Она хранит, кто подписался на уведомления,
и рассылает пуш «Новое в Powermove: Headspin», когда в админке публикуется новый урок.
Он же хранит общий рейтинг (минуты тренировок, ник, город, аватар — без почты и телефонов).
Код — `push-worker.js` в этой папке. Своих паролей у сервера нет: отправлять уведомления может только
тот, у кого есть ключ GitHub с правом записи в репозиторий приложения (то есть ваша админка).

## Как поставить (один раз, ~10 минут)

1. Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (почта + пароль, карта не нужна).
2. Слева **Storage & Databases → KV → Create** (или «Create instance»). Имя: `fedoskin-push` → **Create**.
3. Слева **Compute → Workers & Pages → Create → Start with Hello World** (или «Create Worker»).
   Имя: `fedoskin-push` → **Deploy**.
4. Нажмите **Edit code**. Удалите всё в окне с кодом, вставьте целиком содержимое файла `push-worker.js` → **Deploy**.
5. Вернитесь к воркеру → вкладка **Settings → Bindings → Add → KV namespace**.
   Variable name: `PUSH` (большими буквами), KV namespace: `fedoskin-push` → **Deploy / Save**.
6. Скопируйте адрес воркера — вида `https://fedoskin-push.<ваше-имя>.workers.dev`.
   Откройте его в браузере: должно появиться `{"ok":true,"service":"fedoskin-push"}`.
7. Админка → **Тексты и настройки → Адрес сервера уведомлений** → вставьте адрес → **Опубликовать**.

Готово. Во вкладке «Статистика» видно число подписчиков и есть ручная отправка.
В приложении в Профиле появится общий рейтинг (весь мир / мой город).

Если сервер уже стоял раньше (без рейтинга): Workers & Pages → fedoskin-push → Edit code → вставить новый
`push-worker.js` целиком → Deploy. Остальное не меняется.
После публикации нового урока админка сама отправит уведомление через 3 минуты.

## Счётчик посещений (добавлен 01.11.2026)
Админка → «Статистика» → «Посещаемость»: сегодня и за всё время, 30 дней, страны, устройства.
Нужна бесплатная база D1 (KV для этого не годится: у него всего 1 000 записей в день):
1. **Storage & Databases → D1 SQL Database → Create**, имя `fedoskin-stats`.
2. **Workers & Pages → fedoskin-push → Edit code** → вставить новый `push-worker.js` целиком → **Deploy**
   (в админке есть кнопка «Скопировать код сервера»).
3. **fedoskin-push → Settings → Bindings → Add → D1 database**: Variable name `DB`, база `fedoskin-stats` → **Deploy**.
Таблицы сервер создаёт сам. Лимиты D1 бесплатно: 100 000 записей и 5 млн чтений в день — одно посещение
занимает 1–4 записи. Хранится: хэш случайного номера устройства, тип устройства, страна, день. Без cookie и IP.

## Ограничения бесплатного Cloudflare
- до 100 000 запросов в день и до 1 000 записей в день (новые подписки + обновления рейтинга). Приложение шлёт
  свои минуты не чаще раза в 2–10 минут и только если они изменились — на альфу хватает (~200–500 активных в день);
- рассылка идёт пачками по 40 телефонов, админка сама гоняет пачки до конца.

## Где работают уведомления
- iPhone (iOS 16.4+): только в приложении, добавленном на экран «Домой».
- Android: в Chrome и в установленном приложении.
- Компьютер: Chrome, Edge, Firefox, Safari.

## Видео уроков в Cloudflare R2 (добавлено 09.11.2026)
Админка → «Добавить видео» → «Куда загрузить видео» → **Cloudflare R2**. Бесплатно 10 ГБ, трафик бесплатный.
Видео хранится в хранилище R2, привязанном к этому же серверу, а приложение берёт его по адресу `<сервер>/v/<файл>.mp4`
(сервер отдаёт и куски файла — это нужно для перемотки и для iPhone). Подключить один раз:
1. **R2 Object Storage → Create bucket**, имя `fedoskin-video` (Cloudflare может попросить привязать карту — при объёме
   до 10 ГБ платить не нужно).
2. **Workers & Pages → fedoskin-push → Settings → Bindings → Add → R2 bucket**: Variable name `VIDEOS`, bucket
   `fedoskin-video` → **Deploy**.
3. Обновить код сервера (кнопка «Скопировать код сервера» в админке) → **Edit code** → вставить → **Deploy**.
Загружает админка кусками по 16 МБ (бесплатный воркер принимает до 100 МБ за раз), только с ключом GitHub владельца.
Каждый показ урока — несколько запросов к серверу; лимит бесплатного Cloudflare — 100 000 запросов в день на всё вместе.
